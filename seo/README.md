# Material SEO

Archivos de apoyo para el posicionamiento de Ibérica Seguridad. No forman parte
del bot: son para quien gestiona `ibericaseguridad.com`.

| Archivo | Qué es | Dónde va |
|---|---|---|
| `schema-localbusiness.html` | Datos estructurados `Locksmith` de la empresa | Dentro de `<head>`, en todas las páginas del sitio |
| `playbook-wordpress.html` | Pasos a ejecutar en el WordPress, con los títulos y descripciones de cada página listos para pegar | Se lee, no se publica |

Antes de publicar el schema hay que rellenar los tres campos marcados como
`REVISAR` y, sobre todo, **arreglar primero la dirección de la ficha de Google**:
el schema tiene que repetir exactamente lo que diga la ficha, no al revés.

El diagnóstico completo está en `../PLAN-SEO.md`.

Comprobación una vez publicado: https://search.google.com/test/rich-results
